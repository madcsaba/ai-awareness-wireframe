3 · Micro-interactions (nudges)

During a long generation
  • live token counter + energy estimate
  • "Stop it? ~2,400 tokens so far."
  • progress bar → "Reply is 80% done."
Repeated regenerations
  • 3× the same request reworded →
  • Refine your prompt instead — faster and cheaper than regenerating.
  • suggested prompt template, one click
Hard task on a small model
  • after a weak answer from GPT-5 mini:
  • The large model handles this better — switch to Claude Sonnet?
  • one click → routing logic runs it
